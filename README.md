# PassShare

PassShareは、サイトごとのログイン情報をパスワードボックスにまとめて保存し、必要なときに検索できるパスワードマネージャーです。

- [公式ドキュメント（GitHub Wiki）](https://github.com/AutoDevJapan/PassShare/wiki)
- [Web版](https://pass-share.bm1314.net/) · [デスクトップとブラウザー拡張の配布ファイル](https://github.com/AutoDevJapan/PassShare/releases/latest)
