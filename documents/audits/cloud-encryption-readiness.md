# クラウド暗号化の受入状況

共有ToDo #1163 / #1175。M4は未完了。現在のホステッドAPIは項目の内容をサーバーが読める。

Rust Coreへ、項目全体の暗号化・復号、期待する保存先・版・鍵の世代との照合、
所有者のローカルルート鍵による鍵包みを追加した。
秘密の鍵は通信型に含めず、項目・鍵包みの用途を分けた追加データで差し替えを拒否する。
追加のパッケージはない。既存暗号依存のzeroize機能を有効にし、解決される依存の消去機能をCargo.lockへ反映する。

架空データの試験は全JSONの往復、毎回のnonceの変更、誤った鍵、ID・版・世代・暗号文の改変、
別アカウントへの鍵包みの差し替え、未知形式、過大データと数値範囲の拒否を扱う。
初回5888944では、DockerのCore全61件（追加5件を含む）と逐次Core試験は成功した。
Clippyは新しい暗号化コードの非推奨API使用で失敗した。
別モデルMust4（JSON深さ、内部鍵コピー、平文再確保、非推奨API）と用途差替え試験の指摘を修復した。
深さ境界と容量固定の試験、所有者のボックス・世代・用途差替え試験を追加し、再実行と再レビューを続ける。
初回の成功を修正後の成功に転用しない。全CIは継続する。

未接続: サーバーの暗号文保存・平文互換の制限、全クライアントの鍵保管・WASM、
共有先の鍵確認と配布、失効後の鍵更新、実復旧、既存データの移行と障害時の原本保持。
