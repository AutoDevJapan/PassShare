# PassShare 機能ロードマップ

## 概要

本ドキュメントは、PassShareを1Password同等の使用感で利用できるようにするための機能開発ロードマップです。法的リスクを回避しつつ、ユーザーが期待する機能を段階的に実装します。

---

## 現状（2026年1月時点）

### 実装済み

- [x] CLI（Python）
- [x] SDK（Python / TypeScript / Node.js）
- [x] GPG/Age暗号化
- [x] Git同期
- [x] pass/gopass互換
- [x] Webサイト（ランディングページ、ドキュメント、ダウンロードページ）

### 未実装

- [ ] デスクトップアプリ（GUI）
- [ ] ブラウザ拡張機能
- [ ] モバイルアプリ（iOS/Android）
- [ ] クラウド同期サービス（オプション）

---

## Phase 1: CLI/SDK強化（2026 Q1）

### 目標
既存のCLI/SDKを1Password CLI同等の使いやすさに改善

### タスク

| 機能 | 優先度 | 詳細 |
|------|--------|------|
| インタラクティブモード | 高 | `passshare interactive` でTUI起動 |
| ワンタイムパスワード表示 | 高 | `passshare otp <path>` でTOTP表示 |
| クリップボード自動クリア | 高 | コピー後の自動消去（45秒） |
| テンプレート機能 | 中 | ログイン、クレジットカード等のテンプレート |
| インポート/エクスポート | 中 | 1Password、Bitwarden形式のインポート |
| シェル補完 | 低 | bash/zsh/fish/PowerShell補完 |

### 1Password同等機能との比較

| 1Password CLI機能 | PassShare対応 | 備考 |
|-------------------|---------------|------|
| `op signin` | `passshare init` | 既存 |
| `op item get` | `passshare show` | 既存 |
| `op item create` | `passshare insert` | 既存 |
| `op item edit` | `passshare edit` | 既存 |
| `op item delete` | `passshare rm` | 既存 |
| `op item list` | `passshare ls` | 既存 |
| `op document get` | 未実装 | Phase 1で対応 |
| `op read` | `passshare show -c` | 既存 |

## Phase 2: デスクトップアプリ（2026 Q2）

### 技術選定

| 選択肢 | メリット | デメリット | 推奨 |
|--------|----------|------------|------|
| **Tauri** | 軽量、Rust製、セキュア | エコシステム小 | ★推奨 |
| Electron | エコシステム大、実績多 | 重い、メモリ消費大 | - |
| Flutter Desktop | クロスプラットフォーム | Dart学習コスト | - |

### アーキテクチャ

```
┌─────────────────────────────────────────────┐
│                 Tauri App                    │
├─────────────────────────────────────────────┤
│  Frontend (React + TypeScript)               │
│  - Orynthデザインシステム                    │
│  - passshare-ts SDK使用                      │
├─────────────────────────────────────────────┤
│  Backend (Rust)                              │
│  - ファイルシステムアクセス                  │
│  - GPG/Age暗号化処理                         │
│  - Git同期                                   │
└─────────────────────────────────────────────┘
```

### 主要画面

| 画面 | 機能 | 1Password同等機能 |
|------|------|-------------------|
| ストア一覧 | パスワード一覧、検索、フィルタ | All Items |
| アイテム詳細 | パスワード表示、コピー、編集 | Item Detail |
| 新規作成 | テンプレート選択、フォーム入力 | New Item |
| 設定 | GPG鍵管理、同期設定、セキュリティ | Preferences |
| セキュリティダッシュボード | 脆弱パスワード検出、重複検出 | Watchtower相当 |

### UIモックアップ概要

```
┌────────────────────────────────────────────────────┐
│ PassShare                    🔍 検索...    ⚙️ 設定 │
├──────────┬─────────────────────────────────────────┤
│ ストア   │  メール                                  │
│ ├ ログイン│  ├ gmail.com                           │
│ ├ カード  │  ├ outlook.com                          │
│ ├ ノート  │  └ protonmail.com                       │
│ └ SSH鍵   │                                         │
│           │  SNS                                    │
│ タグ      │  ├ twitter.com                          │
│ ├ 仕事    │  └ github.com                           │
│ └ 個人    │                                         │
├──────────┴─────────────────────────────────────────┤
│ 選択: gmail.com                                     │
│ ユーザー名: user@gmail.com            [コピー]      │
│ パスワード: ••••••••                  [コピー][表示]│
│ TOTP: 123 456                         [コピー]      │
└────────────────────────────────────────────────────┘
```

### 独自性の確保（1Password模倣回避）

- カラースキーム: 緑（#22c55e）+ ダーク（#0a0a0a）
- 「セキュリティダッシュボード」という独自名称
- pass/gopass互換を前面に打ち出す
- 完全無料を強みとして訴求
- CLI/開発者フレンドリーな設計

## Phase 3: ブラウザ拡張機能（2026 Q3）

### 対応ブラウザ

| ブラウザ | 優先度 | 拡張機能API |
|----------|--------|-------------|
| Chrome | 高 | Manifest V3 |
| Firefox | 高 | WebExtensions |
| Safari | 中 | Safari Web Extensions |
| Edge | 低 | Chrome互換 |

### 主要機能

| 機能 | 詳細 | 1Password同等機能 |
|------|------|-------------------|
| オートフィル | ログインフォーム自動入力 | Autofill |
| パスワード生成 | ポップアップで生成 | Password Generator |
| 保存提案 | 新規ログイン時に保存提案 | Save Login |
| 検索 | ポップアップで検索 | Quick Access |
| TOTP | ワンタイムパスワード表示 | 2FA |

### アーキテクチャ

```
┌─────────────────────────────────────────────┐
│           ブラウザ拡張機能                   │
├─────────────────────────────────────────────┤
│  Popup UI (React + Orynth)                  │
│  Content Script (フォーム検出・入力)         │
│  Background Script (データ管理)              │
├─────────────────────────────────────────────┤
│  Native Messaging Host                       │
│  (デスクトップアプリとの通信)                │
└─────────────────────────────────────────────┘
```

### セキュリティ考慮事項

- パスワードはメモリ上でのみ復号
- クリップボードは自動クリア
- 自動ロック機能（アイドル時）
- CSP (Content Security Policy) 準拠

## Phase 4: モバイルアプリ（2026 Q4）

### 技術選定

| 選択肢 | メリット | デメリット | 推奨 |
|--------|----------|------------|------|
| **React Native** | Web資産活用、TypeScript | ネイティブ機能制限 | ★推奨 |
| Flutter | 高パフォーマンス | Dart学習コスト | - |
| ネイティブ | 最高のUX | 開発コスト2倍 | - |

### 主要機能

| 機能 | iOS | Android | 備考 |
|------|-----|---------|------|
| 生体認証 | Face ID / Touch ID | 指紋認証 | ストア解錠 |
| オートフィル | AutoFill Services | Autofill Framework | OS統合 |
| ウィジェット | iOS Widget | Android Widget | 即座アクセス |
| 共有拡張 | Share Extension | Share Intent | パスワード保存 |
| カメラスキャン | QRコード読み取り | QRコード読み取り | TOTP設定用 |

### 同期方式

1. **Git同期（推奨）**: 既存のGitリポジトリと同期
2. **ローカルのみ**: デバイス内に保存
3. **クラウド同期（将来）**: PassShare Cloud（オプション）

## Phase 5: クラウドサービス（2027以降・オプション）

### 概要

セルフホストが困難なユーザー向けに、オプションのクラウド同期サービスを提供

### 機能

| 機能 | 詳細 |
|------|------|
| クラウド同期 | E2E暗号化されたデータの同期 |
| チーム管理 | ユーザー招待、権限管理 |
| 監査ログ | アクセス履歴の記録 |
| SSO | SAML/OIDC対応 |

### 差別化ポイント

- **オプション**: クラウドなしでも完全に機能
- **セルフホスト可能**: 企業向けにオンプレミス版提供
- **GPG鍵ベース**: 既存のGPG鍵をそのまま利用

## リスクと対策

| リスク | 影響 | 対策 |
|--------|------|------|
| 開発リソース不足 | 遅延 | 優先度に基づく段階リリース |
| セキュリティ脆弱性 | 信頼低下 | 定期的な脆弱性診断、バグバウンティ |
| 法的問題 | 中止 | 弁護士レビュー、UIガイドライン遵守 |
| 競合の機能追加 | 差別化困難 | pass/gopass互換性と完全無料を強みに |
