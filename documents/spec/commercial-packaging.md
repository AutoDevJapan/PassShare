# PassShare の料金と提供範囲

料金の基準は、オーナーの 2026-10-04 18:17:17 JST（09:17:17 UTC）の投稿 `1556233740898926625` に従う。この承認は料金の基準を決めるもので、販売開始・新しい支出・稼働保証の承認ではない。[製品監査](../audits/2026-10-04-product-readiness.md)の Must と配布・運用・契約の確認を継続する。

## 料金の基準

| 項目 | オーナーが指定した基準 | 提供範囲 |
|---|---|---|
| 初回導入 | 1社 10,000円 | 導入の基本料金。対象端末・作業内容を見積書に記載 |
| 導入支援 | 1時間 10,000円 | 移行・教育・復旧確認等の作業時間を見積もる。初回導入料金へ無制限に含めない |
| 保守 | 月額 10,000円が基準。オプションにより最大 200,000円 | 対応範囲・時間・オプション内訳を個別契約で定める |
| 個人版サブスクリプション | 1人 980円 | 個人向け。提供機能・対応環境は技術検証後に確定 |
| チームプランの管理者 | 1人 1,980円 | チーム管理を行う管理者の料金 |
| チームプランの通常メンバー | 1人 500円 | 通常メンバーの料金 |
| 追加実装依頼 | 別途見積もり | 保守やサブスクリプションへ無制限に含めない |

チームプランは **管理者1人と通常メンバー1人以上**の契約が必要。管理者0人、通常メンバー0人のチーム契約は販売対象にしない。

チームの基準料金は `1,980円 × 管理者人数 + 500円 × 通常メンバー人数`。最小構成は2人で2,480円、管理者1人＋通常メンバー4人は3,980円、管理者2人＋通常メンバー8人は7,960円。初回導入・導入支援・保守は別の料金項目として見積もり、必要な契約の組合せを説明する。

金額の税の扱い、サブスクリプションの請求周期、日割り、返金、席数の変更時期は投稿で指定されていない。見積書・規約・料金画面の公開前に確定する。未承認の条件を価格へ上乗せしたり、月額・年額・税込表示を独自に確約したりしない。

## 提供する価値と採算

専任の IT 担当がいない企業へ、移行・教育・担当者交代・復旧確認を支援する。競合より安いという主張ではなく、顧客が日常運用を続けられることを販売価値とする。ソフトウェアのライセンス条件と有料の支援契約は区別する。

担当者の原価を時給4,000円と仮定すると、1時間の導入支援料金10,000円との差は6,000円。税・営業・突発対応・移動費・インフラ費は別に必要。実際の作業時間と問い合わせ件数を記録し、保守オプションの範囲と価格を見積もる。月額保守の基準10,000円に24時間対応や無制限の実装を約束しない。

## 契約に記載する事項

- 対応機能・対応 OS・利用人数・管理者と通常メンバーの区分・問い合わせの受付時間。
- 端末ファイルとクラウドで誰が秘密値を読めるか。復旧できる条件と顧客が保管するもの。
- 初回導入と導入支援の分担、保守オプション、追加実装の見積もり方法。
- 請求周期、税、支払期日、更新、解約、返金、解約後のデータ取得期限。
- バックアップの保管期間、復元方法、障害連絡先。復元時間と失ってよい更新範囲は演習で実測する。
- 秘密値を問い合わせへ送らない手順。画面画像と診断情報からも顧客の情報を除く。
