# デスクトップの背景・放置時の施錠（1197 / 1176）

Rustの共通処理が、単調時計で最後の利用者入力から5分の期限を管理する。
一覧取得や同期などの自動処理では期限を延長しない。
フォーカス喪失・背景移行は直ちに施錠し、復帰だけでは開かない。
再起動時も施錠状態から始める。現在の画面とロック画面を使用する。

デスクトップは暗号化ボックスの秘密値をRustで消去し、全項目の読取・検索・
CSV出力・保存を同じ施錠判定で拒否する。画面の保持したマスターパスワード、
一覧・編集・同期設定は既存画面を破棄して消去する。
開く処理の途中に背景移行した場合、その処理の結果で再び開いてはいけない。

モバイルの背景・放置時施錠は未実装のまま1176で継続する。
OSの生体認証画面による一時的フォーカス変化と、本当のアプリ背景移行を
ネイティブ側で区別する必要がある。PIN/生体認証と保護された資格読出しを
一つの解除試行にまとめ、古いlogin/refreshによる保存・削除を世代付きで
直列確定する。全blurの無視や完了後の新世代取得で回避しない。
実Android/iOSでのライフサイクル・生体認証・保護された保存領域は未受入。

```gherkin
Given 開いたパスワードボックスと架空の項目
When 5分間入力せず一覧を自動取得する
Then 期限で秘密値を消去し読取・保存を拒否して再認証を要求する

Given 認証が開始済み
When 背景へ移動してから認証が完了する
Then 古い結果を拒否し復帰後も施錠を維持する

Given 期限直前の開いたボックス
When 前景で実際に入力する
Then 入力から5分に期限を更新する
And 期限切れ後の入力では施錠を解除しない
```

検証は共通Rustの境界値・世代の試験、Desktop本体の実IPC、背景と復帰、
デスクトップの暗号化原本・再認証後の内容一致を含める。
Linux上のモバイル画面を実Android/iOS成功と扱わない。
署名配布、緊急復旧、全22受入、販売完了はこの修正の合格だけで完了にしない。
