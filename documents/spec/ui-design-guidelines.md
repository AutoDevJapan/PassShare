# PassShare UIデザインガイドライン

## 目的

本ガイドラインは、PassShareの独自ブランドアイデンティティを維持し、他社製品（1Password、Bitwarden等）との視覚的差別化を確保するための設計指針です。

---

## 1. ブランドアイデンティティ

### 1.1 デザインコンセプト: "Orynth"

PassShareは「Orynth」と呼ばれる独自のデザインシステムを採用しています。

**コンセプトの特徴:**
- **ダークファースト**: 目に優しいダークモードを基本とする
- **ミニマル**: 不要な装飾を排除し、情報の可読性を最優先
- **開発者フレンドリー**: ターミナル/コード文化を尊重したデザイン

### 1.2 差別化ポイント

| 項目 | PassShare | 1Password | Bitwarden |
|------|-----------|-----------|-----------|
| ベースカラー | ダーク（#0a0a0a） | ライト（白基調） | ダーク/ライト |
| アクセントカラー | 緑（#22c55e） | 青（#0572EC） | 青（#175DDC） |
| デザイン思想 | 開発者向け・CLI文化 | コンシューマー向け | エンタープライズ向け |

## 2. カラーパレット

### 2.1 プライマリカラー（緑）

```css
primary-50:  #f0fdf4  /* 最も明るい緑 */
primary-100: #dcfce7
primary-200: #bbf7d0
primary-300: #86efac
primary-400: #4ade80
primary-500: #22c55e  /* メインアクセント */
primary-600: #16a34a
primary-700: #15803d
primary-800: #166534
primary-900: #14532d  /* 最も暗い緑 */
```

**使用ガイド:**
- `primary-500`: CTAボタン、重要なアクション
- `primary-400`: テキストリンク、アクティブ状態
- `primary-500/10`: バッジ背景（10%不透明度）

### 2.2 セカンダリカラー（パープル）

```css
secondary-500: #8b5cf6  /* アクセント用 */
```

**使用ガイド:**
- 補助的な強調、タグ、特別な状態表示

### 2.3 ダークパレット

```css
dark-800: #171717  /* メイン背景 */
dark-900: #0a0a0a  /* 最深部 */
dark-700: #404040  /* カード背景・ボーダー */
dark-600: #525252  /* ホバー状態 */
dark-400: #a3a3a3  /* サブテキスト */
dark-300: #d4d4d4  /* 本文テキスト */
```

### 2.4 禁止カラー

以下のカラースキームは競合製品との混同を避けるため使用禁止:

- **1Password Blue** (#0572EC, #1A8CFF) - 使用禁止
- **Bitwarden Blue** (#175DDC) - 使用禁止
- 白背景をベースとしたライトモードデザイン - 原則禁止

## 3. タイポグラフィ

### 3.1 フォントファミリー

```css
font-sans: 'Inter', system-ui, -apple-system, sans-serif;
font-mono: 'JetBrains Mono', Consolas, monospace;
```

### 3.2 使い分け

- **JetBrains Mono**: コードブロック、ターミナル出力、パスワード表示

## 4. コンポーネント設計

### 4.1 ボタン

```tsx
// プライマリボタン
<button className="btn btn-primary">アクション</button>

// セカンダリボタン  
<button className="btn btn-secondary">キャンセル</button>

// ゴーストボタン
<button className="btn btn-ghost">その他</button>
```

**デザイン特性:**
- 角丸: `rounded-lg` (0.5rem)
- パディング: `px-4 py-2`
- トランジション: 200ms

### 4.2 カード

```tsx
<div className="card">コンテンツ</div>
<div className="card-hover">ホバー可能なカード</div>
```

**デザイン特性:**
- 背景: `bg-dark-800`
- ボーダー: `border-dark-700/50`（50%不透明度）
- 角丸: `rounded-xl` (0.75rem)

### 4.3 入力フィールド

```tsx
<input className="search-input" placeholder="検索..." />
```

**デザイン特性:**
- 背景: `bg-dark-800`
- ボーダー: `border-dark-700`
- フォーカス時: `border-dark-600` + リング

## 5. レイアウトパターン

### 5.1 許可されるパターン（業界標準）

以下は業界で広く使用されている標準パターンであり、使用可能:

- **3ペインレイアウト**: サイドバー + リスト + 詳細
- **マスター/ディテールパターン**: リストから詳細への遷移
- **検索・フィルタリング**: ヘッダー固定の検索バー
- **モーダルダイアログ**: オーバーレイ形式の編集画面

### 5.2 回避すべきパターン

以下のパターンは1Passwordとの類似性が高いため回避:

- 青い「+」ボタンでの新規アイテム追加
- "Watchtower"という名称の使用
- 1Password固有のアイコンスタイルの模倣
- 白背景＋青アクセントの配色

---

## 6. アイコン

### 6.1 使用ライブラリ

**Lucide Icons** を標準として使用

```tsx
import { Shield, Lock, Users, GitBranch } from 'lucide-react';
```

### 6.2 アイコンサイズ

- 小: `h-4 w-4` (16px)
- 中: `h-5 w-5` (20px)
- 大: `h-6 w-6` (24px)

### 6.3 禁止事項

- 1Password固有のアイコンセットの模倣
- 他社ロゴに類似したアイコンの使用

## 8. 機能名称ガイド

### 8.1 独自命名（推奨）

| 機能 | PassShare名称 | 回避すべき名称 |
|------|--------------|----------------|
| 脆弱性監視 | セキュリティダッシュボード | Watchtower |
| パスワード保管庫 | ストア / Store | Vault（使用可だが独自性を意識） |
| 秘密鍵 | GPG鍵 / Age鍵 | Secret Key（1Password用語） |
| チーム共有 | 共有設定 | Family/Team Vault |

### 8.2 一般的な用語（使用可）

- ログイン、パスワード、クレジットカード、セキュアノート
- 検索、フィルター、タグ、カテゴリ
- エクスポート、インポート、同期

## 9. レビューチェックリスト

新しいUI実装時に確認すべき項目:

- [ ] プライマリカラーは緑（#22c55e）系を使用しているか
- [ ] 背景はダーク（#0a0a0a / #171717）を基本としているか
- [ ] 青系のアクセントカラーを使用していないか
- [ ] Lucide Iconsを使用しているか
- [ ] 1Password固有の機能名称を使用していないか
- [ ] アニメーションは控えめで標準的か
- [ ] Inter / JetBrains Monoフォントを使用しているか

---

## 10. 法的注意事項

本ガイドラインは以下の目的で策定されています:

1. **商標侵害の回避**: 1Password、Bitwarden等の商標を適切に使用
2. **トレードドレス侵害の回避**: 視覚的な類似性を意図的に避ける
3. **独自性の確保**: PassShareの独自ブランドを確立

商用リリース前には知的財産専門の弁護士によるレビューを推奨します。
