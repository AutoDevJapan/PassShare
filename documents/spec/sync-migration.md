## 移行 (#101 / #102)

2026-10-04 の保存の補足: Web の編集は、読み込んだ項目の追加フィールド・識別子・メタデータ・複数 URL を保持する。編集開始時の `version` を PUT へ送り、変更済みなら 409 で拒否する。PostgreSQL は PUT/PATCH の読み取り時の版に対して条件付き UPDATE を行い、同時保存で先の更新を失わない。`version` を省略する旧クライアントは互換性のため受け付けるが、編集開始時からの競合検出は版を送るクライアントだけで保証する。

保存と削除の失敗を画面に表示し、保存失敗時はフォームの入力を残す。読込中・保存中の二重操作と、不完全な一覧からの CSV 出力を防ぐ。CSV は平文で、追加フィールド・添付・複数 URL 等をすべて保全するバックアップではない。出力前に確認し、完全な端末バックアップは .pbox のコピーを使用する。

アカウント・招待・ボックス作成等の変更処理は、ゲートウェイの 502/503/504 応答でも自動再送しない。応答の失敗だけでは保存されていないとは断定できない。読み取りのみ再試行し、作成後の一覧は更新した権限で再取得する。遅れて返る古い一覧で新しいボックスを隠さない。

| 操作 | Desktop | Web |
|------|---------|-----|
| 1Password CSV インポート | `.pbox` 直書き | Connect API 逐次 create |
| 1PUX インポート | Connect API | Connect API |
| 1Password CSV エクスポート | `.pbox` → ファイル保存 | ブラウザダウンロード |
