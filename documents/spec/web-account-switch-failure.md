# Webのアカウント切替と接続失敗

Given 同じ利用者Aの項目フォームに未保存の下書きがある。
When 本人情報がAのままConnect tokenの取得に503が返る。
Then 下書きを保持し、接続が復帰するまで送信を無効にする。復帰後も同じ下書きから操作できる。

Given 利用者Aの下書きを残したタブと、同じブラウザの別タブがある。
When 別タブで正式ログアウト後、利用者Bでログインし、元タブの一覧更新でBの本人情報を取得した後にConnect tokenが503になる。
Then token取得の完了を待たず本人情報をBへ反映する。利用者IDが変わったフォームは旧下書きを消し、送信は無効にする。

本人情報を取得できていない失敗と、取得済みのBに対するtoken失敗は別の状態。取得前の推測で本人をBへ切り替えない。この有限修正は成功した本人情報を既存stateへ先に接続する。

作成応答の喪失による二重保存は別の未解決条件（1197/1482）。アカウント切替の修復だけでM2-C全体を合格にしない。
