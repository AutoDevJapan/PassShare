# PassShare 知的財産レビューチェックリスト

## 2. 特許関連の確認事項

### 2.1 調査済み情報

**1Password (AgileBits Inc.)**
- 15件以上の特許を保有（暗号化方法論、UIイノベーション、セキュリティアーキテクチャ）
- 具体的な特許番号は公開情報では確認できず
- 主な技術:
  - Two-Secret Key Derivation (2SKD): 特許有無不明
  - Secure Remote Password (SRP): Stanford発のオープン標準（RFC 5054）
  - エンドツーエンド暗号化: 一般的な技術

### 2.2 PassShareの使用技術

| 技術 | 出典 | リスク評価 |
|------|------|-----------|
| GPG暗号化 | OpenPGP標準 (RFC 4880) | 低リスク |
| Age暗号化 | オープンソース (filippo.io/age) | 低リスク |
| SRP認証 | Stanford/RFC 5054 | 低リスク |
| TOTP/HOTP | RFC 6238/4226 | 低リスク |
| Git同期 | オープンソース | 低リスク |
| PBKDF2/Argon2 | 業界標準 | 低リスク |

### 2.3 弁護士に確認すべき項目

- [ ] 1Passwordの具体的な特許内容の調査依頼

## 3. 商標関連の確認事項

### 3.1 調査済み情報

**登録商標（使用時に注意が必要）**
- 「1PASSWORD」: 米国特許商標庁登録（Serial No. 88508459）
- 「Bitwarden」: 登録商標
- 「gopass」: 商標登録状況未確認
- 「pass」: 一般名詞のため商標リスク低

### 3.2 PassShareでの使用状況

| 名称 | 使用箇所 | 使用方法 | リスク |
|------|----------|----------|--------|
| 1Password | 比較表 | 比較広告として | 低（事実に基づく比較） |
| Bitwarden | 比較表 | 比較広告として | 低（事実に基づく比較） |
| pass/gopass | 互換性説明 | 技術仕様として | 低（オープンソース） |

### 3.3 弁護士に確認すべき項目

- [ ] 比較表での他社商標使用が比較広告として適法か
