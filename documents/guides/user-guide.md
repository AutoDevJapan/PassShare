# PassShare ユーザーガイド

> 最終更新: 2026-05-28

## 概要

初回セットアップから日常利用まで、PassShare のパスワードボックス操作を説明します。

## 1. アカウント作成

Web ポータル（`/app/signup`）でクラウド用のアカウントを作成します。端末版の .pbox はアカウントなしで使えます。マスターパスワードは端末ファイルを開くためのもので、クラウド用のアカウントパスワードとは別です。

現在のクラウドは、項目の内容をサーバーへ送る方式です。端末版の暗号化と同じ保管方式ではありません。一般向けの配布と販売は検証中です。開発者向けの起動手順は [デスクトップ開発手順](../runbooks/local-dev-desktop.md) を参照してください。

## 2. パスワードボックスを開く

- **Desktop:** `.pbox` ファイルを選択し、マスターパスワードで開く
- **Web:** ログイン後、Connect API 経由でクラウド上のパスワードボックスにアクセス

## 3. ログイン情報の管理

| クライアント | 操作 |
|-------------|------|
| Web | `/app/vaults` → パスワードボックス選択 → CRUD |
| Desktop | 項目追加・検索・コピー（クリップボード自動消去） |
| Mobile / Extension | Connect API 経由 |

## 4. クラウド同期（Desktop）

設定 → クラウド同期で push / pull。競合時はローカル優先またはクラウド優先を選択。

## 5. データ移行

1Password から 1PUX インポートまたは CSV エクスポート → PassShare インポート。

## 6. バックアップと復旧

端末版は .pbox のコピーとマスターパスワードを別々に安全に保管します。現在、緊急キットの値だけでボックスを開く機能はありません。マスターパスワード紛失時に復旧できるとは約束できません。

CSV は平文で、追加フィールド・添付・複数 URL 等のすべてを保全するバックアップではありません。取込後に件数と内容を確認し、元データを検証前に消さないでください。
